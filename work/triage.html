AI Work / Case Study

TRIAGE: root cause analysis for a Mars helicopter

At the JPL hackathon, I solo-built a dashboard that helps engineers find out why a Mars Sample Return helicopter test did not behave as expected.

JPL Mission Critical Award Solo build Live public rebuild

Context

Flight test data is repeatable but dense. Engineers burned time separating "expected variance" from "something is actually wrong," and a wrong call in either direction is expensive.

What I built

TRIAGE combines deterministic statistics with GenAI: the deterministic layer flags where telemetry deviates from expected envelopes, and fine-tuned internal local models turn those flags into plain-language root cause narratives an engineer can accept, edit, or reject. The human makes the call; the tool makes the call faster.

Outcome

TRIAGE won the hackathon's Mission Critical Award for the best JPL solution.

What I learned

In a mission-critical review, trust comes from numbers people can re-derive. So the statistics stay deterministic, the language model only writes the narrative, and the engineer makes the final call. Every AI product I have shipped since follows that pattern.
