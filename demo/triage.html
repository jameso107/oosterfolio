TRIAGE: Flight Edition

Deterministic statistics flag the anomaly. A language model writes the narrative. A human makes the call. And the Evals tab shows you exactly how well the pipeline performs.

Numbers computed, never generated LLM narrates, never computes Human decides

Cached mode uses pre-computed narratives for every flight: instant, offline, zero API calls. Live mode makes a real model call, rate-limited to 10 per hour.

Data: the public Ingenuity (Mars 2020 helicopter) flight log, all 72 flights with per-flight duration, altitude, distance, groundspeed, and mission notes, compiled from NASA status reports via Wikipedia's List of Ingenuity flights. Code and README on GitHub.

TRIAGE was built inside NASA JPL and stays there. This is an independent public rebuild using only public NASA data and my own code, written to show the approach. It is not affiliated with or endorsed by NASA or JPL.

How this is evaluated

The golden set is 22 labeled cases drawn from the public flight record: each case pins an expected anomaly category and a reference narrative. The pipeline's cached outputs are scored two ways. Exact match checks the predicted category against the label. An LLM-as-judge pass (Claude, cached run) scores each narrative 1 to 5 for category correctness, grounding in the record, and calibration of confidence. Every case has a full trace below: inputs, deterministic flags, the exact prompt, the model output, the reference, and the judge verdict, so failures can be traced back through the pipeline to their root cause.

A note on the high match rate: the deterministic layer does the heavy lifting here by design. Categories follow tightly from computed flags plus record notes, so the judge score on narrative quality is where the discriminating signal lives.

What this demo shows

The internal TRIAGE was built at the JPL hackathon to disposition Mars Sample Return helicopter anomalies. This public rebuild keeps its architecture on open data: a deterministic layer computes fleet statistics (median and MAD robust z-scores, fully client-side, zero API calls), an LLM narrative layer turns flags into plain language through a server-side API route (prompt design plus a strict JSON schema, the key never reaches the browser), a human-in-the-loop review flow records every disposition, and a golden-set evaluation with LLM-as-judge scoring and per-case trace analysis makes the quality measurable instead of claimed.
